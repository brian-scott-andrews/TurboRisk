Routines about Players

PActive: returns true if a player was active at the beginning of the game

PAlive: returns true if a player is alive

PArmiesCount: returns the number of armies totally controlled by a player

PCardCount: returns the number of cards that a player holds in hand

PCardTurnInValue: returns the value of a player's next card turn in

PHuman: returns true if a player is human

PMe: returns the ID of the current player

PName: returns a player's name

PNewArmies: returns the number of armies that a player still has to place on his territories

PProgram: returns a player's program file name

PTerritoriesCount: returns the number of territories controlled by a player
