Steps to create a new version of an existing map

To make a variation of an existing map without overwriting it, first open the map in TRMap and save a copy using File > Save As.... Keep the new `.trm` file and its companion artwork together.

  1. Open the map with File > Open map....

  2. Use File > Save As... to create a copy with a new name.

  3. Edit the SVG or BMP artwork in a suitable graphics editor. For BMP artwork, retain distinct, flat territory colors if using TRMap's automatic tracing. SVG artwork should use filled paths for territories.

  4. Re-open the saved map in TRMap and inspect the changed artwork.

  5. For BMP tracing, select each territory and seed its artwork region. Run  Floodfill points - Autofind  to trace the seeded regions. SVG paths can be assigned by clicking each filled path.

  6. If the artwork is geometrically scaled, use  Map point coordinates - Transform  to scale its text-box and floodfill point coordinates. This does not resize the artwork itself.

  7. Use  Validate map  to check the map. Inspect the single-color preview and test the finished map in TurboRisk.

  8. Save the map and keep the TRM and companion artwork together in the game's maps folder.
