Steps to create a new version of an existing map

Here is a summary of the basic steps needed to create a new version of an existing map:

  1. Open the map you want to modify inside TRMap: File > Open... .

  2. Using File > Save as... save it with a new name. This will create new BMP and TRM files.

  3. Open the bitmap image you just created with your graphic editor. Modify the map, but keep the colors of the territories the same of the map you copied from.

  4. Re-open the map in TRMap. The bitmap you just modified will appear in the main window.

  5. Select the Utilities tab and click the  Floodfill points - Clear all  button. TRMap will ask for confirmation, then clears all the floodfill points (but keeps the color definitions).

  6. Click the  Floodfill points - Autofind  button. TRMap will start finding all the floodfill points of your territories. This will take a bunch of seconds.

  7. If something went wrong (painting went out from designed regions), close without saving, correct your bitmap, open the map again in TRMap and restart from point 5.

  8. If the map has the same shape of the original map and has just been stretched to a new size, you can now use the  Text box points - Transform  function to make TRMap calculate the new text box points for you. Calculate the size factors by the ratio of the two bitmaps:

    X_size_factor = new_map_width / old_map_width
    Y_size_factor = new_map_height / old_map_height

    Type these two values in the text boxes just right of the "*" and click the  Text box points - Transform  button.

  9. Check your work using the  Validate map  button. Correct mistakes and validate again until everything's ok.

  10. Select Simulation option of the Active map control. Change simulation color and click every territory to check if every region changes color as you expect it does.

  11. When you're satisfied with your work, save the map and exit TRMap.
