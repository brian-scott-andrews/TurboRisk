TRMap

TRMap is an utility software supplied with TurboRisk and located in the same folder.

You're invited to experiment with TRMap. However, instead of altering any of the maps provided with TurboRisk, you are suggested to make a copy of it and work on the copy itself.
To do this, open a map in TRMap and save it with a new name (using File > Save as...). This will copy the bitmap and the TRM to new files. Anyway, in case you alter the original maps, you can always load them again from the TurboRisk webpage.

The File menu

This menu presents pretty much standard options to create a new map, to open an existing map file or to save a map file to a selected folder.

The File > New... menu item shows a dialog where you are requested to select a bitmap file. In fact, TRMap can create a new TRM file, but you need a bitmap file to link to the TRM file.

The File > Open menu item will make TRMap load the bitmap and the TRM file associated to it.

With the File > Save as... function TRMap saves the map file to a new file name (extension TRM) and at the same time creates a copy of the bitmap file with the same name and extension BMP.

With TRMap you can save map files to any folder, and open them from any folder, but please remember that when you want to use those maps in TurboRisk you have to move them into the Map subfolder of the main TurboRisk folder.

The Tool window

After you load a map, TRMap shows its Tool window, which contains three tabs: Map, Territories and Utilities.

Map

This tab gives you access to the descriptive information of the map: description, author and revision. Just type in these fields whatever information you think that describe your map.

In the same tab you find a button to select the font name and size used for the text box showing the number of armies. Choose any font that you think is appropriate to make your map pleasent and readable. You can also choose the color of the text: either black text over white background (default), or white text over black background.

Use the simulation option (see below) to verify how the map appears with a given font.

Territories

The Territories tab allow you to define the three properties of each territory: color, floodfill point and text box point. You will input these data using the active map, which is the map shown in the main TRMap window.

The Active map selector has five options:

  1. Nothing: shows the bitmap "as is", no action is allowed.
  2. Floodfill points: shows the floodfill points of the selected territory like small white crosses. Anytime you click on a given point on the map, that point will be added to the list of floodfill points, provided that it has the same color of the first one. In fact, the first floodfill point is used to "pick up" the color of the territory.
  3. Text box: shows the text box of the selected territory. Click on the map to move its top left corner in a new position.
  4. Links: the map shows white lines connecting the first floodfill point of each territory to the first floodfill point of each bordering territory. This view is provided just to check the topology of the map, no action is allowed.
  5. Simulation: every territory gets painted with the selected simulation color, and all the text boxes appear. You can now change the simulation color and click on the single territories to check that everything works well.

Utilities

This tab contains a few utility functions that may speed up the process of defining a new map or of adapting an existing map to a new size.

  •  Floodfill points - Autofind : usually a map contains many multi-region territories, which would require the user to define a floodfill point for each region. This function speeds up the process: provided that you have defined the color for each territory (in a new map this means to define at least one floodfill point per territory), it will create a floodfill point in every other region of the same color.
  •  Floodfill points - Clear all : this button simply clear all the floodfill points of all territories.
  •  Text box points - Transform : the purpose of this function is to simplify the porting of a map to a different size version of the same map. You can ask TRMap to transform all the text point coordinates into new ones using addition and multiplication.

Validation

At the bottom of the window you find the  Validate map  button. It performs a number of tests to ensure that your map has been properly set up. The result of the test will appear in a Log window.
