TRMap

TRMap is the map editor supplied with TurboRisk. It edits `.trm` map metadata and territory points and imports SVG or BMP artwork.

Keep a backup when editing a map. Use File > Save As... to save a copy under a different name before changing a bundled map.

Open, import and save

Use File > New from SVG or BMP... to import artwork, or File > Open map... to open a `.trm` package, SVG, or BMP. A map package contains the `.trm` file and its companion artwork. Keep the files together when copying the map into TurboRisk's `maps` folder. Saving a vector map writes a `.trm` and sibling `.svg`; when it has a raster background, TRMap also writes a sibling `.bmp`. Existing bitmap-backed maps remain bitmap-backed when saved.

Map details and territory data

The Map tab contains the description, author, revision, and font settings for army labels. The Territories tab selects a territory and lets you work with its floodfill points and text-box point on the map.

The game's topology is fixed at 42 territories and six continents; TRMap does not edit territory names, continents or borders. Floodfill points identify regions that belong to a territory. A map can contain up to 20 floodfill points for each territory.

SVG import assigns a selected filled path to a territory when clicked. BMP import uses exact flat-color regions: select a territory and click a region to seed it, then use Floodfill points - Autofind to trace seeded regions into SVG paths. This raster tracing is intended for simple, flat-color maps; anti-aliased edges, texture, holes, or complex shapes may need cleanup in an SVG editor. Raster artwork is retained as a separate background.

Utilities and validation

The view selector displays floodfill points, text-box points, fixed links, or a single-color floodfill preview. The preview checks seed coverage; it is not a full game or ownership simulation. Map point coordinates - Transform scales text-box and floodfill point coordinates only; it does not resize the artwork. Use  Validate map  to check map points, vector assignments and fixed topology before using the map in a game.
