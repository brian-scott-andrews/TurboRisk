Routines about Continents

CAnalysis: returns information about the number of players and armies on a continent

CBonus: returns the number of armies (per turn) which the control of a continent entitles to

CBorder: returns a border territory of a continent

CBordersCount: returns the number of border territories on a continent

CEntriesCount: returns the number of entry points on a continent

CEntry: returns an entry territory of a continent

CLeader: returns information about player who controls the greatest number of territories on a continent

COwner: returns the owner of continent

CTerritoriesCount: returns the number of territories belonging to a continent

CTerritory: returns the ID of a territory belonging to a continent
