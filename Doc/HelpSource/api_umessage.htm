UMessage procedure

Syntax

procedure UMessage(M: string);

Description

Displays message M in a modal window, and waits until the user presses the OK button.

Line breaks in M can be obtained by incorporating CR+LF characters in the string:

UMessage('First line'+#13#10+'Second line');

The message window actually appears only if UMessage has been enabled with a call to UMessageOn. By default UMessage is off.

When UMessage is called, TurboRisk copies the content of the Log window into the clipboard, so as you can paste and examine it in the Notepad or any other text editor of your choice.

UMessage is intended as a debug tool and should not be used in TRPs to be released in the public domain.
