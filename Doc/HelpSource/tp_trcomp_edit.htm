Editing a TRP

The main window of TRComp is divided into six areas:
  • The menu bar: gives access to all the functions of TRComp.
  • The toolbar: provides a quicker way to activate some of the same functions you find in the menu bar.
  • The editing area: a large area where you can write and edit the source code of your TRP.
  • The API list: a pane on the left containing the complete list of the TurboRisk API functions and procedures.
  • The function list: a pane on the left containing the complete list of the functions and procedures defined in the program.
  • The message list: a pane at the bottom, which shows the list of errors, warnings and hints reported by TRComp when you compile your TRP.

The Editor

The text editor incorporated in TRComp is a full featured editor, with syntax highlighting to make your programs more readable.

Its many functionalities can be accessed through the  Edit  menu, the toolbar, some keyboard shortcuts and the popup menu activated by a right click inside the editing area.

The editor also features unlimited undo-redo of your changes, complete text find/replace functionalities (supporting also regular expressions) and bookmarking (up to ten bookmarks).

TRComp supports contextual help: when you press F1 and the cursor is on a valid API function, the help system opend at the proper API documentation page.

The API list

The API list contains all the TurboRisk API calls, grouped into categories. If you leave the mouse pointer on a name for a while, a hint appears that describes the purpose of the function and its parameters.

If you double-click on a name, that function name will be inserted in your source code.

The function list

The function list contains a list of the procedures and functions defined in your program, sorted in alphabetical order. It's a dynamic list, which changes whenever you add, change or remove a procedure or a function.

If you double-click on a name, the cursor in the editing area will move to the first line of that procedure/function.

The message list

This pane is a read-only area where TRComp shows compilation errors, warnings and hints.

Double-click on an error message will make the cursor in the editing area move to the corresponding line.
