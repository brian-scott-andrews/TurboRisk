Editing a TRP

The main window of TRComp is divided into these areas:
  • The menu bar and toolbar provide file, edit, compile and run commands.
  • The editing area is a Pascal source editor with syntax highlighting and line numbers.
  • The API list is a categorized browser of the documented TurboRisk API functions and procedures.
  • The routine list shows procedures and functions found in the source.
  • The results pane shows compile diagnostics and output captured while a routine is tested.

The Editor

The source editor uses Pascal syntax highlighting and line numbers. Use the  Edit  menu or the toolbar for undo, redo, cut, copy and paste.

TRComp tracks unsaved edits and prompts before discarding them. Compile the current source from the  TRP > Compile  menu or toolbar button. Double-click a diagnostic with a source location to jump to that line. F1 opens the TRP API reference; it is not context-sensitive to the symbol under the cursor.

The API list

The API list contains the TurboRisk API calls grouped by category.

Double-click an API name to insert it at the editor's current caret position.

The routine list

The routine list is refreshed as the source changes and contains the procedure and function declarations recognized by TRComp.

Double-click a routine to move the editor caret to its declaration. Select a routine and choose  TRP > Run selected routine...  to test it.

The results pane

Compile errors and other diagnostics appear in this pane. Routine test results and captured TurboRisk utility calls are also shown here; see Running a TRP routine.
