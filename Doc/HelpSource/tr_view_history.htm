History

Use Open history / TRSim log... to open a game history.txt file or a TRSim/TRSimCLI .sgl game log without editing its columns. Opening a file replaces the displayed results, not the game's saved history. Only completed games contribute to the History, Ranking and Compare tabs. The source label reports how many unfinished games were excluded, including timeouts, turn-limited games, errors and user-aborted games. Invalid records are reported with their file name and line number.

The History tab contains a list of the completed games: date, number of players and list of the players' names starting from the winner and proceding in reverse order of elimination.

This list is by default ordered by date, but you can click on any column heading to get the list ordered by that column.

The Ranking tab shows a grid where each player is accounted of the number of games played, number of won games, percentage of won games, points and average points per game. The points are granted according to the following rule:

  • Winner: points = Number of players
  • 2nd place: points = Number of players - 1
  • 3rd place: points = Number of players - 2
  • ...
Click on any column header of the Ranking grid to order the table by that value.

The Compare tab allow to compare how two specific players performed in the games where both of them where playing, showing how many times each of the two scored better than the other. Just select two players and click the  Analyze  button.
