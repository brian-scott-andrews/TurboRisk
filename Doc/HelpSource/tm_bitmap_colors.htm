Colors

These color rules apply when preparing a BMP map for TRMap's raster-region tracing. TRMap uses exact-color, four-connected regions to find the part of the bitmap containing a seed point.

Use a distinct flat color for each territory you intend to trace. Similar but not identical colors are treated as separate regions.

Separate adjacent regions clearly. Anti-aliased boundaries, texture, enclosed holes and complex shapes may not trace as intended; inspect the SVG paths created by Floodfill points - Autofind and clean them up in an SVG editor if necessary.

Vector SVG maps use filled paths to define territory artwork and do not rely on the BMP color-tracing workflow described here. See TRMap for both import workflows.
