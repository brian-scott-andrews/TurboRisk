System Requirements

  • Windows 95/98/NT/2000/ME/XP/Vista/7
  • About 3MB to 20MB of free disk space, depending on installation of companion programs and maps.
  • Mouse
  • Monitor capable of at least 800x600 recommended

TurboRisk doesn't install any DLL or OCX or any other component in your Windows folders. It doesn't use the registry, except to register its Uninstall program.

For this reason TurboRisk is highly portable, you can move it from one machine to another simply copying its folder. Similarely, you can run it from any memory device with no need to install it on the target machine.
