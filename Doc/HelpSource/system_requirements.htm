System Requirements

Run a release build on a platform for which that release provides binaries. The Lazarus/Free Pascal source can be built on supported Lazarus platforms; platform-specific LCL packages and the optional `fpvectorial` package are needed for building the map editor.

The graphical applications require a display and pointing device. Storage requirements depend on the executable package, maps, player scripts and logs you choose to keep. Keep TurboRisk's configuration, maps and players in the locations expected by the game; see Installation.
