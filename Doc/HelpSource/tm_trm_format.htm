The TRM format

A TurboRisk Map file (`.trm`) is a text file that stores map metadata and territory points. The artwork is kept in a companion SVG or BMP file. Together these files make up a map package. A TRM contains:
  • Description of the map.
  • Author's name.
  • Revision note.
  • Name and size of the font used to show the number of armies in the territories.
  • For each territory, the color used to represent it.
  • For each territory, the coordinates of the text box used to show the number of armies.
  • For each territory, a list of floodfill points.

Floodfill points are the points where the color is "poured" to paint the territory. Each territory needs as many floodfill points as the number of different regions it's formed by. Each territory can have up to 20 floodfill points. In bitmap-backed maps, floodfill points identify regions to paint; in SVG-backed maps, the territory paths provide the fill geometry and points are used by the map data.

Though you can open a TRM file with any text editing program (like Notepad) and write or modify those information directly, the TRMap tool offers a much more convenient way to do that. Keep the `.trm` file with its sibling `.svg` or `.bmp` artwork when moving the map. Territory borders and the 42-territory topology are defined by the game, not by the TRM file.
