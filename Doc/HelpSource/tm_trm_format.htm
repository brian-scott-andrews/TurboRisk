The TRM format

A TurboRisk Map file (TRM) is a text file that contains the following elements:
  • Description of the map.
  • Author's name.
  • Revision note.
  • Name and size of the font used to show the number of armies in the territories.
  • For each territory, the color used to represent it.
  • For each territory, the coordinates of the text box used to show the number of armies.
  • For each territory, a list of floodfill points.

Floodfill points are the points where the color is "poured" to paint the territory. Each territory needs as many floodfill points as the number of different regions it's formed by. For example, in the standard map Alaska has one floodfill point, Northest Territory has two of them, Greenland four and Indonesia twelve (every island is a region). Currently TurboRisk allows a maximum of 20 floodfill points.

Though you can open a TRM file with any text editing program (like Notepad) and write or modify those information directly, the TRMap tool offers a much more convenient way to do that.
