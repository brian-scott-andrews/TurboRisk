Program structure

Any TurboRisk program must contain five procedures with predefined name and parameters that are called by TurboRisk when the computer player is expected to take some decision or some action.
Each procedure receives some "var" parameters (the Pascal convention to say a parameter is passed by reference instead of by value), which are used to return to TurboRsk its results. This is the typical program structure of a TRP program:

{
Program: My_program_name

Author: My_name - Release date

Description: Describe the strategy of your program.
}
 program MyProgram; // this statement is optional

procedure MyProcedure(...); // define as many procedures and functions as you want
begin
  ...
end;

function MyFunction(...): ...;
begin
  ...
end;

// The following procedures must exist in the program.
// Their position in the code is not important.

procedure Assignment(var ToTerritory: integer);
begin
  // The ASSIGNMENT procedure is called during the initial assignment of territories
  // to know which is the program's choice. Return the result in the ToTerritory
  // var parameter.
  ...
end;

procedure Placement(var ToTerritory: integer);
begin
  // The PLACEMENT procedure is called at the beginning of each turn to decide where
  // to place new armies. It is called N times, each one to place a single army, until
  // all new armies are placed. Return the result in the ToTerritory var parameter.
  ...
end;

procedure Attack(var FromTerritory, ToTerritory: integer);
begin
  // The ATTACK procedure is called at attack time. Each call to ATTACK corresponds
  // to a single throw of the dice. Return the program's choice in the FromTerritory
  // and ToTerritory var parameters. Set FromTerritory to 0 if you decide not to attack
  // and end your attack phase.
  ...
end;

procedure Occupation(FromTerritory, ToTerritory: integer; var Armies: integer);
begin
  // The OCCUPATION procedure is called after a successful attack. The parameters
  // FromTerritory and ToTerritory are properly set by TurboRisk when entering the
  // routine. Return the number of armies you want to move in the Armies var parameter.
  ...
end;

procedure Fortification(var FromTerritory, ToTerritory, Armies: integer);
begin
  // The FORTIFICATION procedure is called after the attack phase. Return the program's
  // choice in the FromTerritory, ToTerritory and Armies var parameters.
  // Set FromTerritory to 0 if you decide not to move any army and end your turn.
  ...
end;

begin
  // You can place here some optional code which is executed just once at the beginning
  // of a new game.
  ...
end.

The comment section at the beginning of the program is optional. However, if you plan to release your TRP to the public, you're kindly invited to write there all the information you want to share with the TurboRisk users to explain how your TRP behaves. In fact, a comment section delimited by { and } and placed at the very beginning of the program will get shown to the user in the Program selection window.

The simple.trp program is a very simple TRP included to provide a starting point for developers to understand how TRPs work.
