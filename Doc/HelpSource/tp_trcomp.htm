TRComp

TRComp is a desktop editor, compiler and routine tester for TurboRisk player programs (TRPs).

TRComp provides a Pascal source editor with syntax highlighting, a browser for TurboRisk API calls, a live list of routines in the current source, compiler diagnostics, and an isolated way to call an individual procedure or function. It is intended for developing and testing TRPs; it does not run a complete game.

Use the following topics to learn how to:

  • Edit and compile TRP source code.

  • Run a routine with a simulated game context.
