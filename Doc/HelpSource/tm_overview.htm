Custom Maps Overview

A TurboRisk Map is the computer equivalent of the board used in the traditional game, its the area where the game takes place.

From version 2.0 on, TurboRisk allows the user to create and use custom maps. If you create a map, you're encouraged to send a copy of it to the author of TurboRisk to be shared with other users.

A TurboRisk Map is made of two files:

  • A bitmap file with some required properties (extension BMP).
  • A TurboRisk Map file (extension TRM) which define the properties of the map in a format that TurboRisk can understand.
Those two files must have the same name (just different extension), and need to stay in the Maps subfolder of the TurboRisk main folder, otherwise TurboRisk won't find them.
