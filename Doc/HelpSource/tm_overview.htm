Custom Maps Overview

A TurboRisk map defines the artwork, territory points and descriptive information used for a game. The territory names and borders follow the game's fixed 42-territory, six-continent topology.

Custom maps can use SVG vector artwork or BMP raster artwork. Use TRMap to import artwork, edit map points and validate the map.

A saved map consists of a TRM metadata file and companion artwork:

  • An SVG file for vector artwork, or a BMP file for raster artwork.
  • A TurboRisk Map file (extension TRM) containing descriptive fields, territory points and other map properties.
Keep the TRM and its companion artwork together. Copy the map package into TurboRisk's maps folder for use in a game.
