Routines about Territories

TArmies: returns the number of armies on a territory

TBorder: returns a bordering territory of a given territory

TBordersCount: returns the number of borders of a territory

TContinent: returns the ID of the continent which a territory belongs to

TDistance: returns the distance between two territories

TFront: returns a bordering enemy territory of a given territory

TFrontsCount: returns the number of bordering territories occupied by opponents

TIsBordering: returns true if two given territories border each other

TIsEntry: returns true if a territory is an entry point of a continent

TIsFront: returns true if a territory is has at least one bordering territory occupied by opponents

TIsMine: returns true if a territory is owned by current player

TName: returns the name of a territory

TOwner: returns the owner of territory

TPressure: returns the total number of enemy armies bordering on a territory

TShortestPath: finds the shortest path to go from a territory to another territory

TStrongestFront: returns information about the strongest enemy bordering on a territory

TWeakestFront: returns information about the weakest enemy bordering on a territory

TWeakestPath: finds the weakest path to conquer all the territories up to a destination
