Overview

One of the unique features of TurboRisk is that it allows any user to program his/her own computer players (also called AI players or "bots" in the game terminology).

A TurboRisk Program (TRP) is a text file with extension ".trp", which contains instructions that define the behaviour of the player for every situation.

The TRP files must be placed in the Players subfolder of the main TurboRisk folder to make them visible to TurboRisk.

TRPs use the bundled PascalScript compiler and runtime with the TurboRisk API. This is not the complete Delphi or Free Pascal language; see PascalScript and TurboRisk API limits.

The companion program TRComp provides a source editor, compiler diagnostics, API browser and isolated routine tester.

If you write a TRP, you are encouraged to send it to the TurboRisk author to be shared with other users of the game.
