Customizing Players

When you start a new game, TurboRisk offers you the possibility to change the list of the players.

1. Manual configuration

By clicking the  Change  button associated to a specific player, TurboRisk shows a window where you can modify the parameters associated with that player:

Type: Human or Computer (TRP).

Name: (human players only) this is the name of the player as it will appear in the turn indicator, in the Statistics window and in the History log of the played games.

Program (computer players only): the name of the TurboRisk Program (TRP) which drives the computer player. The small  ...  button opens a window showing a short description of all the available programs.

TurboRisk release includes many different TRPs, each one designed to use a specific strategy, and thus all of them resulting in different "personalities".
Most of this programs have been written by TurboRisk users. The section Making a custom TRP describes how anybody with some programming experience can design and write his/her own TRP.

Color: the color used to represent the player in the map, in the turn indicator and in the Statistics window. Black and white are not allowed.

Cards Handling (human players only):

  • Manual: the players sees his cards every time at the beginning of his turn, even if there are no valid combination to trade in.
  • Smart: TurboRisk shows the cards only when there is at least a valid combination to trade, and the player can decide what to do.
  • Full auto: TurboRisk automatically trades the cards in anytime there is a valid combination (as it does for the computer players) and the player never sees his cards.

Keep log: if this check box is active, the player's moves get traced in the log window.

2. Quick setup

The quick setup box of the New game window allows you to quickly pick up an entire combination of players.

You can either pick-up one of the five pre-defined combinations (named Very easy, Easy, Medium, Hard, Very hard) or define your own favourites combinations of players.

To create a custom combination, simply configure the individual players, then type the name you want to assign to that combination in the Setup name box, then finally click the  Save setup  button.
