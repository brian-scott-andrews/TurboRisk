Game level

You can decide the difficulty of the game by choosing the players you play against. Generally speaking, you make a game more difficult by playing against a higher number of opponents, and by choosing stronger ones. The many possible combinations result in almost infinite levels of difficulty.

However, TurboRisk offers a quick way to set the level of the game to some preset combination of players. When you start a new game, you can use the Quick setup box to choose among five possible predefined levels: very easy, easy, medium, hard, very hard.
