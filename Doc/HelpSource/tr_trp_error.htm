TRP Error

A TurboRisk computer player (TRP) is a program, and as any piece of software it might contain errors. Its author probably spent countless hours in writing and testing it. Nevertheless, there are so many different situations that may happen during a game, that some of them might lead the TRP to behave in a wrong way.

TurboRisk obviously doesn't allow any TRP to make invalid moves (for example, to "jump" from a territory to another one which does not border with it), and if this happens TurboRisk shows the TRP Error window.

In that case you can:

  • Press the  Continue  button, and go on with the game.
  • Press the  Dump memory  button, which saves a copy of the game situation to a file.
  • Press the  Quit TurboRisk  button, which makes TurboRisk stop the current game and close.

The second option allows the author of the TRP (or the author of TurboRisk) to fix the TRP itself, so as it won't do again the same kind of mistake. In fact, the  Dump memory  button produces a snapshot file, a copy of the global status of the game.

This file is located into the subfolder Dump of the main TurboRisk folder, and is named trdump_YYYYMMDD_HHNNSS.trd, where YYYY, MM, DD, HH, NN and SS are respectively the year, month, day, hour, minute and second when the snapshot has been taken.

If you want to help making TurboRisk a better program, you are kindly requested to email this "trdump_..." file to the author of TurboRisk, who in turn will pass it to the author of the TRP.
