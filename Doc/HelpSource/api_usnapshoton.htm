USnapShotOn procedure

Syntax

procedure USnapShotOn;

Description

Enables the UTakeSnapshot function, which is, by default, disabled.

USnapShotOn is typically invoked in the main begin-end section of the program, to enable the usage of UTakeSnapshot during the debugging of the TRP.

Example:

begin
  USnapShotOn;
end.

Before releasing a TRP for public use, the calls to USnapShotOn must be removed, or commented out, or replaced with calls to USnapShotOff.
