TWeakestPath function

Syntax

function TWeakestPath(ST, DT: integer; var TT, PL, EA: integer): boolean;

Description

Finds the weakest path to go from the start territory ST to the destination territory DT.

The "weakest path" is the path that contains the minimum number of enemy armies and that doesn't cross territories already owned by the current player.

The "cost" of a path is computed considering the total number of enemy armies along the path plus 1 per each territory to conquer (corresponds to EA + PL). TWeakestPath returns the path with the minimum cost among all the possible paths.

Returns false if ST or DT are out of range or if the path doesn't exist.

The "var" variables will contain return information on the path from ST to DT:

  • TT: first territory in the path.
  • PL: path length (number of territories to conquer).
  • EA: total number of enemy armies along the path.
