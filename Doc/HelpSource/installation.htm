Installation

Download the TRInstall.exe installation program, run it and follow the instructions. You will be prompted with a few installing options.

A complete TurboRisk installation will put the following files into the selected TurboRisk folder:

  • TurboRisk.exe: The TurboRisk game.
  • TurboRisk.ini: Configuration file.
  • TurboRisk.chm: The TurboRisk help file.
  • TRMap.exe: TurboRisk Map Editor, a companion tool to create custom maps.
  • TRComp.exe: TurboRisk Compiler, a companion tool to develope artificial intelligence players.
  • Doc folder: contains TurboRisk additional documentation.
  • Maps folder: contains the map files (extension is ".trm").
  • Players folder: contains the artificial intelligence players (extension is ".trp").
