Installation

Obtain the TurboRisk package for your platform from the project's release page, or build the programs from source using the developer instructions in the repository's Readme. There is no current TRInstall.exe installer.

Keep each executable with the data folders it uses. The game needs its configuration file, maps and players; the companion programs can be installed alongside it as needed.

  • TurboRisk: the game.
  • TurboRisk.ini: game configuration file.
  • TRSim and TRSimCLI: graphical and command-line simulation tools.
  • TRMap: map editor for SVG and BMP map artwork.
  • TRComp: editor, compiler and routine tester for TRP scripts.
  • Doc folder: documentation and help sources.
  • maps folder: game maps and their companion artwork.
  • players folder: TurboRisk player scripts (extension .trp).
