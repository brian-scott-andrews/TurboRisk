Steps to create a new map

TRMap accepts vector SVG artwork or a BMP with flat-color territory regions. The import workflow differs slightly for each format.

  1. Prepare artwork. For a BMP, use flat, clearly separated colors and avoid anti-aliased boundaries or textures if you plan to trace territories. For SVG, draw filled territory paths.

  2. Choose File > New from SVG or BMP... and open the artwork.

  3. Fill in the description, author, revision and label font fields in the Map tab.

  4. Select a territory in the Territories tab. For SVG artwork, click its filled path to assign it. For BMP artwork, click inside a flat-color region to record its seed.

  5. For BMP artwork, repeat for each territory, then run  Floodfill points - Autofind  to trace the seeded regions into vector paths. Inspect the result; complex, textured, anti-aliased, or holed regions may require cleanup in an SVG editor.

  6. Set each territory's text-box point in the map view. If adapting a map to artwork at another scale, use the coordinate transform for the text-box and floodfill points; it does not resize the artwork.

  7. Use  Validate map  to check points, vector assignments and topology. The game uses a fixed 42-territory, six-continent topology.

  8. Check the map with the floodfill points, text-box points, links and single-color preview views. The preview checks seed coverage only; test the map in TurboRisk for actual gameplay.

  9. Save the map. Keep the `.trm` file with its sibling `.svg` and, if present, `.bmp` artwork. Copy the package into TurboRisk's `maps` folder to use it in a game.
