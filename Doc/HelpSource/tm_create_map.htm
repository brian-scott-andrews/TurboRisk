Steps to create a new map

Here is a summary of the basic steps needed to create a new map from scratch:

  1. Create your bitmap image of the map, following the instructions stated in the previous Creating the bitmap section.

  2. Run TRMap. Select File > New... from the menu and open the bitmap you just created. It will appear in the main window.

  3. Fill in the descriptive fields in the Map tab of the Tool window

  4. Select the Territories tab and the option Floodfill points of the Active map control.

  5. Select the first Territory, then click on the map to mark its first floodfill point.

  6. Repeat step 5 for each territory, just one floodfill point per territory (this will define their color as well).

  7. Save the map: File > Save.

  8. Select the Utilities tab and click the  Floodfill points - Autofind  button. TRMap will start finding all the other floodfill points of your territories. This will take a bunch of seconds.

  9. If something went wrong (painting went out from designed regions), close without saving (if you saved at point 7, otherwise save now!), correct your bitmap, open the map again in TRMap and restart from point 8.

  10. Select the Territories tab and the option Text box points of the Active map control.

  11. For each territory, click on the map to define the coordinates of its text box. You can click as many times you like to properly adjust the position.

  12. Check your work using the  Validate map  button. Correct mistakes and validate again until everything is ok.

  13. Select Simulation option of the Active map control. Change simulation color and click every territory to check if every region changes color as you expect it does.

  14. When you're satisfied with your work, save the map and exit TRMap.
