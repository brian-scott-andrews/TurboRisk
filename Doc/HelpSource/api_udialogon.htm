UDialogOn procedure

Syntax

procedure UDialogOn;

Description

Enables the UDialog function, which is, by default, disabled.

UDialogOn is typically invoked in the main begin-end section of the program, to enable the usage of UDialog during the debugging of the TRP. By default UDialog is off.

Example:

begin
  UDialogOn;
end.

Before releasing a TRP for public use, the calls to UDialogOn must be removed, or commented out, or replaced with calls to UDialogOff.
