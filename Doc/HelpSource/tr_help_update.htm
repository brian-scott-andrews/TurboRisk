Check for news and updates

Using the Help > Check for news and updates menu function you can check whether the TurboRisk website contains any news about TurboRisk, or if it contains new versions, new maps and/or new TRPs.

Obviously, to be able to perform this activity your computer needs to be conncted to the Internet, and able to reach the TurboRisk website.

This windows shows an upper section about the news, and a lower section abaut the files.

The News section automatically shows any information that has been published after the last time you checked. However, you can select any date and read all the news published since that date.

The Files section lists all the files loaded on the TurboRisk web page. The items that don't exist on your computer - or that exist but in an older version - are automatically checked for update.

By clicking the  Install/Update selected files  button TurboRisk will download the selected files and install them into the proper folders.

Through the Options > Preferences menu you can instruct TurboRisk to automatically check for updates at startup.
