ULogOn procedure

Syntax

procedure ULogOn;

Description

Enables the ULog function, which is, by default, disabled.

ULogOn is typically invoked in the main begin-end section of the program, to enable the usage of ULog during the debugging of the TRP.

Example:

begin
  ULogOn;
end.

Before releasing a TRP for public use, the calls to ULogOn must be removed, or commented out, or replaced with calls to ULogOff.
