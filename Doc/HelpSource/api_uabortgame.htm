UAbortGame procedure

Syntax

procedure UAbortGame;

Description

UAbortGame asks TurboRisk to stop the current game, and makes it behave exactly like if the user had pressed the Stop button.

UAbortGame doesn't exit the current procedure, it simply sets a TurboRisk flag that makes the game stop as soon as possible (which is usually after having finished the current move).

For this reason, in the typical usage you may also want to explicitly exit the current procedure.

Example:

procedure Attack(var FromTerritory, ToTerritory: integer);
begin
  ...
  if <MyErrorCondition> then begin
    // error, abort game
    ULog('...description of the error...');
    FromTerritory:=0; // attack is aborted
    ToTerritory:=0;
    UAbortGame;
    exit; // exit Attack procedure
  end;
  ...
end;

UAbortGame is intended as a debug tool and should NEVER be used in TRPs to be released in the public domain.
