Uninstallation

TurboRisk can be uninstalled in two ways:

  • If you used the Automatic installation, just run the TurboRisk Uninstall program that you find in the same Windows menu that contains TurboRisk.

  • If you used the Manual installation, simply remove the directory and its sub-folders from your system.

TurboRisk didn't put anything in your Windows and System directories.
