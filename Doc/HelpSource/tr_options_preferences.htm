Preferences

The Options > Preferences menu items shows a window where you can customize the TurboRisk interface.

Toolbar

You can decide if you want to activate the toolbar, and which buttons should appear on it.

Map

TurboRisk can alter the color of the territories hoovered by the mouse or selected for an attack. You can change how the colored are altered (how much they are made darker or lighter) in the two cases.

Game

Available options:
  • Ask for confirmation before aborting a game in progress - Forces TurboRisk to ask for a confirmation when you want to abort the current game.
  • Advanced options in Attack window - This checkbox enables two buttons in the Attack window:  Attack until my armies ≤ N  and  Attack until enemy's armies ≤ N .
The former online update preference was removed during the Lazarus port. It is not available in the current application.
