PascalScript and TurboRisk API limits

TRP files use the bundled PascalScript compiler and runtime, not the complete Delphi or Free Pascal language and runtime. Which language constructs and library routines work depends on the compiler configuration and the functions registered by TurboRisk. A construct accepted by another Pascal compiler is not necessarily available to a TRP.

Static and dynamic arrays are used by TRP scripts. For dynamic arrays, SetArrayLength is available; see Types, Variables, Expressions.

TurboRisk exposes its game operations through the documented TurboRisk API; it does not provide a general-purpose Delphi/FPC runtime to TRPs. In particular, do not assume that host-language features such as arbitrary class libraries, operating-system calls, DLL loading or inline assembler are available to a script.

Use TRComp's compiler as the authoritative check for a particular script and consult the API reference for the functions it can call. If a script compiles but depends on undocumented runtime behavior, it may still fail when run by TurboRisk.
