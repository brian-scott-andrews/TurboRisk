Unsupported Pascal features

The following PASCAL features are currently not supported by the TurboRisk script interpreter:

  • Static arrays, use dynamic ones instead. SetLength is not implemented, use SetArrayLength instead.
  • Nested functions, you cannot declare functions inside other functions.
  • Classes are not allowed.
  • Pointers types are not allowed.
  • The "Interface", "Units", "Includes" and "Absolute" clauses are not supported.
  • Asm: inline assembler code is not supported.
