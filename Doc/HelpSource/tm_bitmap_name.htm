Naming the files

The map file name should be short, descriptive and possibly with no spaces inside (for people running TurboRisk on non-Windows machines). For example your My map files could be named:

  my_map_small.bmp
  my_map_medium.bmp
  my_map_large.bmp

Inside the TRM file you can place a description of the map, the author's name and a revision note, so there's no need to try to make these info fit into the name file.
