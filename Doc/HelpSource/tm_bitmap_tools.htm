Required tools

First of all, you need a program to create and edit bitmaps. Together with Windows you got Paint, which is not a very sophisticated graphic editor, but serves the purpose.

Any other editor of your choice will work, provided that's able to save your graphics in bitmap format.

You have no constraints on the size of your map. If you plan to share it with other users, you are invited to consider the making of different versions for different screen sizes. Typically, you would need a small map for screens of 640x480, a medium map for 800x600 and a large map for 1024x768 and upper resolutions.
