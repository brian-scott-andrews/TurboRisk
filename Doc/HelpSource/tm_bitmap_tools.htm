Required tools

TRMap can import SVG artwork directly or import a BMP as raster artwork. For SVG maps, draw filled paths that correspond to territories; paths can be assigned to territories in TRMap.

For BMP maps, use an image editor that can save bitmap files. Territory regions should use flat, distinct colors. TRMap's tracing uses exact-color, four-connected regions, so anti-aliased borders, textured fills, holes and complex shapes may require manual cleanup or conversion to SVG. The imported bitmap remains a separate background when traced regions are saved as SVG.

TRMap supports map dimensions up to 20,000 pixels per side and 10 million pixels total. Map-point coordinate transforms scale text-box and floodfill points, but do not resize the artwork. Keep artwork files together with the `.trm` file when moving a map.
