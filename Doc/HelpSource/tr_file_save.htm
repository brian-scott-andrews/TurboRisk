Saving a game

The File > Save menu item saves the current game.

You can save the game only at the very beginning of the turn of a human player, before he starts placing his/her armies.

The game is saved in a text file with extension "TRG" (TurboRisk Game).

Everything about the state of the game gets saved, including the definition of the players and the rules. When you restore a game, your current Rules and Players options will be overwritten with those saved in the file.
