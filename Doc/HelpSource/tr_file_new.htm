Starting a new game

You can start a new game selecting the File > New menu item or clicking the corresponding button on the Toolbar.

TurboRisk shows a window containing the currently defined players (see Customizing Players).

  1. Select which players will take part in the game by marking the check boxes on the right of the players' names. Alternatively, you can change the entire list of players by choosing a setup name from the Quick setup box.

  2. Click the  OK  button to start the game.
The game starts with the Assignment phase: according to your preferences (see Customizing Rules) TurboRisk will either randomly assign the territories to the players, or each player in turn will be required to click on an unassigned territory to claim it, until all of them have an owner and the game can start.

Use the status bar at the bottom of the main window to see which player is in turn. The status bar also shows a brief text describing the required/possible actions.
