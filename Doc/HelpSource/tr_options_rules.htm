Customizing Rules

The Options > Rules menu item allow you to customize many of the rules that are in place during a TurboRisk game.

The window has three tabs:

Board setup

The Assignment of territories option controls the initial assignment. TurboRisk supports two alternative methods:
  1. One at a time, in turn: players take turns claiming territories by placing one army on an unoccupied territory.
  2. Randomly: all the territories are assigned by TurboRisk at random.

The Initial armies table controls how many armies each player receive at the beginning of the game, depending on the number of players. TurboRisk defaults to 30 armies each, but you can change this number according to your preferences.

Cards

The Cards trade in value options determines how a card set is converted into armies. Traditionally, there are two ways to do that: the first based on combination and the second based on progression.

In the combination method the value of a set is based on the particular combination of cards the player is going to trade.

In the progression method (default) the value comes from the number of trades the player have done up to the moment.

Combination values is a short table of values applicable only if the combination method has been selected. This table controls how many armies the player receives if he trades in three artillery cards, three infantry cards, three cavalry cards or one of each kind.

Similarely, the Progression values table defines the values of the card sets when the progression method has been selected. This table allow the user to explicitly define the value of the first 8 trades, and an increment to use from the 8th trade on.

The Max card held parameter controls how many cards a player can keep in hand before being forced to trade them in. The default is 5 cards.

Checking the Trade captured immediately check box you can decide what to do when a player captures another player's card by eliminating him. If checked (the default), the cards can be traded just immediately after they've been captured, otherwise they'll be traded at the beginning of a new turn.

Troop move

Troop movement ends turn: like the traditional board game, TurboRisk allows only one movement of troops (fortification). However, you can decide if this must end the turn or is allowed also in the middle of it.
The computer players always fortify at the end of their turn.

Default rules

The  Reset to default rules  button reset all the rules to those of the traditional board game (which is also the initial setup of the game after installation).
