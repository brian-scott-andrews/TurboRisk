UTakeSnapshot procedure

Syntax

procedure UTakeSnapshot(M: string);

Description

Saves a snapshot of the game. The snapshot is actually taken only if UTakeSnapshot has been enabled with a call to USnapShotOn. By default UTakeSnapshot is off.

A snapshot is a copy of the global status of the game saved to a file with name trdump_YYYYMMDD_HHNNSS.trd, where YYYY, MM, DD, HH, NN and SS are respectively the year, month, day, hour, minute and second when the snapshot has been taken.

In case the snapshot is taken during a run of TRSim, the file name has the same structure but is also postfixed with _simgame_GGG, where GGG is the number of the game in the simulation.

In either cases, the dump file gets saved in the Dump subfolder of the main TurboRisk folder.

The message M is included in the snapshot file.

Snapshots can be loaded into the TRComp context to analyze a particular situation.

When invoked from TRComp, UTakeSnapshot does not create a file, but just shows a modal window with message M.

UTakeSnapshot is intended as a debug tool and should not be used in TRPs to be released in the public domain.
