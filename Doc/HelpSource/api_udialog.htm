UDialog function

Syntax

function UDialog(M, B: string): integer;

Description

Displays message M in a modal window, and waits until the user presses one of the B buttons.
  • M is a string that can contain line breaks, obtained by incorporating CR+LF characters in the string.
  • B is a comma-separated list of button names, for a maximum of 5 buttons.

Examples:

UDialog('My message','Continue;Stop');
UDialog('Line 1'+#13#10+'Line 2','Button1;;;;Button5');

UDialog returns an integer number, corresponding to the button pressed by the user (1-5), or 0 if the user closes the dialog window without clicking any button (pressing ESC or clicking the standard close window button).

Example:

case UDialog('Houston, we have a problem!','Log;Stop') of
  1: ULog('Problem');
  2: begin
    UAbortGame;
    exit;
  end;
end;

The dialog window actually appears only if UDialog has been enabled with a call to UDialogOn. By default UDialog is off.
If UDialog gets called without a previous call to UDialogOn, it always returns 0.

When UDialog is called, TurboRisk copies the content of the Log window into the clipboard, so as you can paste and examine it in the Notepad or any other text editor of your choice.

UDialog is intended as a debug tool and should not be used in TRPs to be released in the public domain.
