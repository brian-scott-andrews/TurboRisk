Log

The Log window contains a trace of the moves made by a player, provided that the Keep log check box has been made active for that player in the Options > Players menu.

Purpose of this window is to allow you to analyze the actions performed by a player during its turn: the computer players play so fast that there's no time to understand what happens just reading the status bar. Without the log, you would just see the territories conquered on the map and the changes in the Statistics window.

The log trace is especially useful to test and debug TurboRisk players (TRPs).

Log actions... writes the current game's complete available public action history to a separate JSONL file and streams subsequent actions, independent of the players' Keep log settings. Use Stop action log to stop recording; closing the Log window does not stop it. Compatible existing action logs are appended, not overwritten. See Public action history for the format and the HCount / HGet script API.
