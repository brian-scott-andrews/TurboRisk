UMessageOn procedure

Syntax

procedure UMessageOn;

Description

Enables the UMessage function, which is, by default, disabled.

UMessageOn is typically invoked in the main begin-end section of the program, to enable the usage of UMessage during the debugging of the TRP.

Example:

begin
  UMessageOn;
end.

Before releasing a TRP for public use, the calls to UMessageOn must be removed, or commented out, or replaced with calls to UMessageOff.
